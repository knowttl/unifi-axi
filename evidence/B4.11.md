# B4 regression gate

`pnpm verify:packaged -- --task B4.11` installs one packed artifact and runs the existing B1 through B4 standalone synthetic journeys.
The installed executable is used for discovery, credentials, reads, preview, confirmation, execution and reconciliation.
Authenticated child processes use the socket deny preload and can reach only the task-owned fake service.

The NORM-002 matrix exercises the ten routes whose retained contracts declare a bodyless 200 response in each version.
Each available route asserts the exact request, the selected resource and unchanged neighbour, acknowledgement outcome, failed HTTP status, failed verification and no second mutation for a repeated request ID.
Deletion becomes verified only after absence is observed.
Restart and port power-cycle acknowledgements remain accepted because resource reads cannot prove the action completed.
The bodyless routes are OP-011, OP-020, OP-022, OP-023, OP-027, OP-034, OP-040, OP-050, OP-063 and OP-071.

The combined regression also exercises confirmation binding for network force defaults, firewall ordering zone selectors, voucher filters and exact target sets, and credential-source references.
The separate opt-in Artium proof rejects stale host credential revisions before vendor access.
Hosted writes remain unavailable because the frozen host does not provide durable write custody.

The packaged report distinguishes passed refusal assertions from B4 closure and exits nonzero when source blockers or skipped native checks are present.
CF-007 still blocks the 11.0.97 device paths, including adoption, removal, restart and port actions.
Those rows report `blocked-by-CF-007`; the affected gate reports `blocked`, names issue #33 and does not claim successful mutation coverage.
Native Windows and live commissioning remain pending.
The bodyless matrix attempts its routes on Windows instead of returning before exercising them.
Durable native Windows mutations remain unavailable, so a Windows run cannot establish B4 closure.
Public list and detail assertions exercise both Wi-Fi types and all existing Wi-Fi setting fixtures, firewall policy fixtures, managed-network fixtures, client types and access states, VPN types and metadata variants in both retained versions.
These assertions compare public output with synthetic records, including overview projection and credential redaction.
Full reconciliation of every variant-position obligation remains incomplete; the added public read assertions do not establish complete ledger closure.
The configured pipeline test runs without an Artium fixture and prints an explicit skip reason.
Artium results require a separate frozen-fixture run with its revision and package digest recorded alongside the final head.
